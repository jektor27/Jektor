# Jektor Browser — браузер для AI Chat

Лёгкий браузер для AI Chat под Windows на движке Microsoft Edge WebView2.
Одна форма, много вкладок, свой WebView2 в каждой. Рабочее пространство для AI
(на стартовой странице — быстрые ссылки на Qwen AI, GigaChat и другие сервисы).

- Язык интерфейса: русский
- Платформа: Windows 10 / 11 (x64)
- Исходный код открыт под лицензией MIT

## Возможности

- Вкладки: открыть, закрыть, дублировать контекстным меню, переключение.
- Закладки (Ctrl+D) и история посещений.
- Три темы оформления: Jastas Dark, Light Minimal, Cyberpunk.
- Очистка кеша и истории (кнопка 🧹, Ctrl+Shift+Del, пункт в настройках) с выбором периода.
- Режим экономии памяти: движок переводится в низкое потребление, телеметрия в `browser.log`.
- Один экземпляр: повторный запуск активирует уже открытое окно.
- Проверка Microsoft Edge WebView2 Runtime при старте с понятным сообщением.
- Стартовая страница с быстрыми ссылками (Qwen AI, GigaChat, Яндекс, Флаер Гусев).
- Горячие клавиши: F11 (полный экран), Ctrl+R (обновление), Ctrl+D (закладка), Ctrl+Shift+Del (очистка данных).

## Где хранятся данные

Профиль, закладки, история, настройки и лог хранятся в:

```
%LOCALAPPDATA%\Jektor
```

Чтобы держать всё рядом с программой (portable-режим), создайте пустой файл `portable.flag`
рядом с `Jektor.exe`. Можно также задать свой каталог переменной `JEKTOR_DATA_DIR`.

## Установка (готовая сборка)

1. Скачайте архив `Jektor-x.y.zip` из раздела Releases и распакуйте в любую папку.
2. Запустите `Jektor.exe`.
3. Нужен установленный **Microsoft Edge WebView2 Runtime** (обычно уже есть в Windows 10/11).
   Если его нет, программа подскажет ссылку на установку.

Файл `.exe` не подписан сертификатом, поэтому Windows SmartScreen может показать предупреждение
«Неизвестный издатель». Это нормально для открытых проектов — нажмите «Подробнее» → «Выполнить в любом случае».

## Запуск из исходников

Требуется Python 3.10+ (проверено на 3.14).

```bat
python -m pip install -r requirements.txt
python native_browser.py
```

## Сборка exe

```bat
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean jektor.spec
```

Готовая сборка появится в папке `dist\Jektor`.

## Структура проекта

```
native_browser.py   — весь браузер (интерфейс, вкладки, WebView2, очистка данных)
jektor.spec         — конфигурация сборки PyInstaller
jektor.ico          — иконка приложения и окна
requirements.txt    — зависимости для запуска из исходников
```
