# Privacy Policy — Jektor Browser

Last updated: 2026-10-12

Jektor Browser is a lightweight web browser. It is a local desktop application
and does not run any server-side component of its own.

## What we collect

**Nothing.** Jektor Browser does not collect, store, or transmit any personal
data, telemetry, analytics, or usage statistics. There is no account system and
no tracking.

## What is stored on your computer

The following data is stored **locally on your device only**, in
`%LOCALAPPDATA%\Jektor` (or next to `Jektor.exe` in portable mode):

- browser profile and cache (managed by Microsoft Edge WebView2);
- bookmarks and history;
- application settings;
- a local log file `browser.log` used for diagnostics.

This data never leaves your computer unless you explicitly export it.

## Network connections

Being a browser, Jektor connects to websites **that you choose to open**. These
connections are made by the Microsoft Edge WebView2 runtime and go directly to
the websites you visit, in the same way as any other browser.

Jektor itself does not contact any server owned by the project.

## Third-party components

- **Microsoft Edge WebView2 Runtime** — rendering engine. Its data handling is
  governed by the
  [Microsoft Software License Terms and Privacy Statement](https://privacy.microsoft.com/privacystatement).
- **pythonnet / clr_loader** — used to host the WebView2 engine.

Please also review the privacy policies of the websites you visit.
